# peekform

Peek CSV/TSV form tables for quick inspection and cleanup.

**Site:** https://theworker02.github.io/peekform/

## Install / run

```bash
git clone https://github.com/theworker02/peekform.git
cd peekform
node src/cli.js
node --test
```
